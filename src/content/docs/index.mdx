## How to use this

This course assumes you already have Python and an editor set up, with a working **Run**
button. Nothing here explains how to install anything, and you will never be asked to
type a command to start your own program. Click Run instead, and let the editor worry
about which folder your file is in.

Each unit has two pages. Read the **Exercises** page and work through it, then open the
**Solutions** page and compare. The solutions explain why each answer is right, not just
what it is, so they are worth reading even when you got it right.

Do the exercises in order. Each unit assumes the one before it, and the later units lean
on the earlier ones much more than they look like they do.

Two habits matter more than anything else in this course:

- **Type the code yourself.** Copying and pasting teaches your fingers nothing.
- **Predict before you run.** Write down what you think will happen. Being wrong is the
  useful part.

## If you get stuck

Read the error message from the **bottom up**. The last line says what went wrong, the
line above it says where, and the top of the message you can ignore for now.

Then check the [glossary](/cheat-sheets/glossary/) for any word that stopped you, and the
[error reference](/cheat-sheets/errors/) for whatever Python just told you.
